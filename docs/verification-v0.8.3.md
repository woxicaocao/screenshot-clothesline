# 截图晾衣架 0.8.3 验证说明

## 本次修改

普通预览与悬浮图片共用独立图片窗口控制器。图片页全部接收指针事件，非按钮区域左键拖动移动整个原生窗口；取消原先的图片内部平移。拖动使用主进程系统鼠标的 DIP 坐标，松开、失焦、取消捕获、关闭窗口时结束。

滚轮、缩放按钮及键盘修改图片比例，同时改变原生窗口尺寸。每张图维持比例和 1 DIP 外框，窗口可超出屏幕，缩放下限为 64×48。实际绘制面积不超过 1600 万像素、最长边不超过 8192 像素且倍率不超过 16，达到限制显示实际结果。适应屏幕回当前显示器工作区；图片始终使用原文件，不重编码或新增缓存。

每个图片窗有常驻置顶与关闭按钮，定位到屏幕可见部分右上角；允许窗口超屏，但至少保留 64×48 DIP 可操作的一角。普通预览默认不置顶，悬浮默认置顶，改变其中一窗不会影响衣架、其他图片窗或便签。右键菜单提供完整操作，缩放工具在紧凑窗口通过菜单访问。

新增 IPC 仅允许已注册图片窗口及其主 Frame 操作自身；返回实际窗口边界、图片布局、倍率、可见区域、置顶及状态版本。拖动按帧合并，缩放最多一个请求在途，后续请求合并，避免回调乱序和尺寸反馈循环。

## 验证范围

165 项逻辑测试全部通过，其中新增图片控制与几何测试 21 项。源码图片功能 31 组、便签功能 18 组通过；最终 ZIP 解压版同样 31 + 18 组通过，便签全窗口页面错误为 0。29 个程序源文件、运行元信息和随包使用说明与最终源码一致。

最终程序验证了真实鼠标拖动使原生窗口位置改变、从置顶按钮按下拖鼠标不会移动窗口、漏发松开事件时能结束拖动、64×48 实际缩小和菜单关闭、超屏控制区、滚轮锚点及按钮中心缩放。模拟 DIP 锚点与真实 user32 输入在记录中分别注明。

为排除其他软件遮挡，真实鼠标验证只将该隔离图片窗临时置顶，完成后恢复此前置顶值；松开后等待前后端都结束拖动，再恢复光标。未改变生产默认置顶状态。

最终程序在强制 100% / 125% / 150% 渲染比例下验证了衣架宽度、图片窗口跟随缩放、细边框和独立置顶。浏览器在非整数比例下会把 1 CSS 像素边框取整到物理像素；布局检查使用真实分数像素视口尺寸，避免将取整误认为厚框或布局偏移。

具体通过项、原生输入方式、实际窗口尺寸、显示条件与打包一致性以交付 `verification` 目录中的记录为准。测试使用独立数据与示例图片，不改写日常剪贴板，不向微信等外部程序发送测试图片。

真实鼠标验收仅操作已校验句柄的隔离测试图片窗口，完成后松开按键并恢复鼠标原位置；其他受控坐标分支单独记录，不混同原生输入结果。

强制 100% / 125% / 150% 渲染比例的检查未改变 Windows 系统缩放。不同 DPI 的多显示器实际移动只有具备相应显示器时才记录为实测；否则以纯逻辑覆盖并明确保留人工检查。

本版不新增常驻图片窗口或服务，不重新进行内存对照测量。旧版程序、源码、交付包和用户数据继续保留。
