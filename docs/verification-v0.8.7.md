# 截图晾衣架 0.8.7 验证说明

新增从文件夹拖入本机静态图片，支持 PNG、JPG/JPEG、WebP，一次最多 100 个文件。来源文件仅以读取句柄访问，导入将原始字节保存为程序独立副本；来源文件哈希和内容保持不变。衣架仍加载小缩略图，预览和导出使用原图。

保存成功后才新增卡片。无效、损坏、重复、动态或超过限制的文件分别处理，不会把文字、文件夹或网页链接作为照片保存。批量文件逐张读取和解码；单文件限制为 40 MiB、4000 万像素，读取中检测文件变化，失败可重新拖入。

Electron 44.7.0 的原生图片接口不能直接解码部分 WebP；本版按需复用衣架已有渲染进程进行解码，随后释放画布和 ImageBitmap。原 WebP 字节保留，不用转换 PNG 替换原图；没有新增常驻窗口、依赖服务或图片缓存。解码请求单张在途，主进程验证来源窗口、主 frame、单次标识、格式与尺寸；超时、窗口销毁和失败后可重试。

拖入期间临时保持衣架展开，结束、取消、失焦和超时后恢复自动隐藏与点击穿透。可见绳线、工具栏、卡片和空衣架提示卡可接收拖入；普通透明空白继续穿透。暂停自动捕捉仍可手动导入。

## 验证结果

- 191 项单元测试通过，包括原有逻辑、本机文件导入、来源文件保留、像素去重、读取上限、保存失败与重试，以及解码回包来源限制和超时回收。
- 33 组原有功能回归通过：异步剪贴板收集、暂停与恢复、原图预览、真实鼠标窗口拖动和边框调整、拖出载荷、自动隐藏、托盘和模拟 100% / 125% / 150% 比例下的布局。
- 新增 12 组本机拖入集成验证，源码及最终 Windows exe 均通过。通过 Chromium 拖放协议传入真实磁盘文件，验证 PNG、JPEG、WebP 的原始字节、缩略图、去重、无效混入、暂停、失败重试、预览和原格式导出、自动隐藏回收、来源文件不变与重启恢复。
- 打包程序通过 18 组便签、多图回归及 7 组赞赏验证，页面错误为 0。赞赏测试等待原生窗口销毁完成，避免渲染目标先关闭造成错误计数。
- 最终 ASAR 内 36 个程序源文件与当前源码逐字节一致，打包元信息与源码一致，版本为 0.8.7，Electron 保持 44.7.0。electron-builder 按标准去除开发依赖、脚本与构建配置。Windows ZIP 和源码 ZIP 生成 SHA256SUMS.txt，并检查压缩包完整性。

实际系统缩放为 150%，未修改用户显示设置。Chromium 的真实文件拖放检查不等于人工操作资源管理器的 Windows OLE 路由验收；资源管理器到衣架、微信真实拖放发送、多块不同 DPI 显示器之间的操作仍属于人工检查范围。没有发送聊天消息、修改系统剪贴板或改动日常数据。

本版未重新作整机内存对照测量。没有增加常驻渲染窗口；WebP 解码和大图导入期间会产生临时内存，占用随图片尺寸变化，不保证所有场景低于 100 MiB。测试文件、旧发布包和用户数据保留。
