# 0.8.0 内存测量

2026-10-13，在同一台电脑、2560×1440 虚拟显示器、100% 缩放下，分别测量 0.7.0 与 0.8.0 候选免安装程序。两轮显示条件一致，运行中均未发生显示配置变化。之后仅增加了便签重叠时的 Ctrl+V 焦点保护，没有新增进程或计时器；最终 ZIP 解压程序的空衣架再次测得 **70.8 MiB**（3 次样本中位数）。下表的完整场景数据属于前一候选，最终修订完整验证了 46 组桌面行为，内存复测范围为空衣架。

主指标为全部应用进程的 Windows **私有工作集合计**，包括主进程、图片/便签渲染进程、GPU 和 utility 进程；单位 MiB。每场景取 3 次样本中位数。空衣架静置 20 秒，其余场景静置至少 4 秒后采样。不强制 GC、不裁剪工作集、不清理缓存来制造较低数字。调试控制器和 PowerShell 采样器不计入应用，但附加调试本身的开销包含在结果内。

| 场景 | 0.7.0 | 0.8.0 |
| --- | ---: | ---: |
| 空衣架 | 72.3 | 70.7 |
| 连续保存 20 张 640×420 图片 | 156.0 | 148.3 |
| 再保存 10 张 2560×1440 大图，共 30 张 | 129.3 | 129.5 |
| 打开一张大图预览 | 171.0 | 145.9 |
| 关闭预览后 | 136.2 | 132.5 |
| 一张大图悬浮 | 157.8 | 139.3 |
| 三张大图悬浮 | 200.1 | 190.7 |
| 关闭全部悬浮窗后 | 145.5 | 138.4 |
| 衣架自动收起 | 139.3 | 126.3 |
| 隐藏到托盘 | 142.9 | 131.9 |

这是一轮同机对照，部分场景有明显采样波动，不能把表中差值当成固定下降幅度。最终程序大图场景的样本范围为 125.1–167.6 MiB；20 张图片场景为 147.0–149.6 MiB。大图场景中位数比 20 张图场景低，与内存回收时机有关，不意味着图片越多越省内存。完整报告同时保留私有提交量和含共享页的工作集，不能用这些不同口径互相替代。

本次没有新增常驻进程。三分之一窗口减少绘制面积和同时显示的卡片；便签摘要仅复制最多 700 字符，图片查找只复制单条索引，长便签字数统计不创建整段字符数组。这些优化保留原图、完整文字和多窗口能力。总体改善有限，连续收集图片或打开多个大图窗口仍可能超过 100 MiB，不能承诺所有场景低于 100 MiB。

原始记录在交付目录 `verification/memory-baseline-matched.json`、`memory-packaged.json`、`memory-final-idle.json` 和 `memory-comparison.json`。首轮显示环境不同的基线、源码测量也保留在项目的 `test-artifacts/v0.8.0`，没有混作最终成品对照。
