# 截图晾衣架 0.8.6

把截图、网页图片和文字便签夹在桌面的棉质晾衣绳上，随时回看。支持 Windows 10 / 11 x64。

## 直接运行

1. 完整解压 `release/v0.8.6/screenshot-clothesline-0.8.6-win-x64.zip`。
2. 若旧版还在运行，先右键旧版托盘图标选择 **退出**。
3. 双击解压目录里的 **截图晾衣架.exe**。无需安装 Node.js，程序旁边的依赖文件需一起保留。
4. 使用 Win + Shift + S 或微信截图，把图片放入剪贴板，新图片通常在 2 秒内挂上。启动或恢复收集时会跳过剪贴板已有图片。

新版继续使用旧版截图、便签和设置。衣架沿用 0.8.1 的宽度，约为 **当前显示器宽度的 40%**，不固定为 1680 像素；分辨率、系统缩放变化或拖到另一块显示器时重新计算，工作区域不足时自动缩短。窗口和显示器都按 Windows 逻辑像素计算，不重复乘除缩放比例：1920 像素宽屏幕、100% 缩放时约占 768 像素；3840 像素宽屏幕、150% 缩放时约占 1536 实际像素。高度仍为 260 逻辑像素。旧版位置保留，旧版宽度会自动更新。已有 JPEG / WebP 图片继续支持；请用 0.5.0 或更新版本查看，较早版本的索引读取器只支持 PNG。

较窄的衣架使用图标工具按钮，鼠标停留会显示操作提示；更窄时工具排列成两行。添加便签、粘贴、拖动、暂停、置顶、自动隐藏和隐藏到托盘始终保留。图片和便签仍可横向翻看。

工具条新增普通样式的 **赞赏** 按钮。点击后在独立窗口展示二维码，关闭按钮、窗口右上角关闭或 Esc 均可关闭；重复点击会显示已有窗口。二维码原图完整保留，不自动弹出、没有提醒红点。窗口仅点击时创建，关闭后销毁，不增加常驻窗口，也不暂停衣架自动隐藏。

## 复制网页图片后粘贴

Chrome、Edge 和其他能够把图片复制到系统剪贴板的程序均可使用，不需要浏览器扩展或连接码。

1. 在网页图片上右键，选择 **复制图片**。
2. 把鼠标移到展开的晾衣架范围内。如果衣架已经收起，先移到对应的屏幕顶部，让它展开。
3. 按 **Ctrl+V**，图片保存成功后挂到衣架左端。无需先点击衣架取得键盘焦点。

**复制图片地址**、复制文字和复制文件路径不会提供可用的剪贴板图片，按 Ctrl+V 时会提示没有可添加的图片。程序依据剪贴板当前内容读取图片，不能判断图片是否来自网页右键；其他软件复制的图片和截图也可以粘贴。

手动粘贴在 **暂停自动收集** 时仍可用，不抢走浏览器焦点。自动收集保持原有行为，因此复制的新图片可能在按 Ctrl+V 前就已经挂上；想等按键后再添加网页素材，可以先点击暂停。重复图片不会再次挂上，只有保存成功后才增加照片；保存失败时显示提示，可以再次按 Ctrl+V 重试。

Ctrl+V 仅在衣架可见、展开且鼠标实际悬停在其页面上时由衣架处理；程序结合鼠标事件与位置检查，在鼠标离开、衣架收起或隐藏后释放快捷键。若快捷键已被其他程序占用、注册失败，会提示点击工具条的 **粘贴** 按钮添加；按钮平时也可直接使用。

请复制网站的 **大图**。保存的是浏览器或来源程序放入剪贴板的完整像素，无法凭空获得比剪贴板内容更清晰的图片。浏览器可能已经把 JPEG、WebP 等转成剪贴板位图，晾衣架将它保存为 PNG，不保证保留网站原文件的编码、动画或元数据。

新版已取消浏览器右键扩展入口和本地连接服务。此前加载的旧扩展不再用于添加图片；无需安装或配对。旧版扩展源码和连接文件保留，不自动删除。

## 缩略图和原图

- 衣架页面只读取 **最大 288×176 的缩略图**，按比例显示；不把原图作为缩略图加载。
- 点击照片和选择悬浮时才由图片窗口读取原图。
- 拖到聊天、文件夹或其他程序时交给目标程序的是 **保存的原图文件**，保留图片尺寸。截图和手动粘贴图片保存为 PNG；旧版已保存的 JPEG、WebP 保留其原文件与格式。目标程序需支持该格式，聊天软件可能还需点击发送。
- 旧版缩略图会按需生成更小的缓存，原缩略图和原图保留；主动删除照片时才清理对应缓存。

更小的缩略图能减少显示时的解码内存，效果随图片比例和同时显示数量变化。继续保留 0.8.0 的优化：减少获取单张便签或照片时的整份正文与记录复制，便签字符计数逐个码点遍历，避免为全文建立临时字符数组。右键便签菜单和本版细边框不增加常驻窗口或渲染进程。

实际内存随图片尺寸、便签长度及同时打开的窗口数量变化。Electron 仍有基础开销，不能保证大图处理、预览、多个便签或多个悬浮窗在所有场景下低于 100 MiB。关闭不用的图片和便签窗口可释放对应窗口资源；衣架继续使用小缩略图，只在打开大图或拖出时处理原图。本版未重新进行内存对照测量，历史记录继续保留，不将旧版数字当作本版保证。

## 图片细边框

普通图片预览和悬浮图片均使用 **1 逻辑像素外框**。鼠标停在窗口四边或四角时，会显示调整大小的箭头，按住拖动即可改变窗口宽度和高度。图片自动按比例适应窗口，完整显示、不拉伸、不裁切；窗口比例与图片不同时会留空白。边缘有透明的鼠标感应范围，方便抓住细边框，不增加可见边框厚度。

按住图片内部或窗口空白处可以移动整个窗口，按钮仍正常点击。移动保持图片尺寸和倍率，高 DPI 显示缩放下连续拖动也不会让窗口越变越大。窗口最小为 **64×48**；极小或细长图片仅保留操作所需空间。置顶、关闭按钮向可见区域内侧稍作留边，方便同时操作按钮和右上角尺寸调整。

滚轮向上放大、向下缩小，**图片和窗口边框一起改变大小**，回到与图片比例一致的窗口；鼠标指向的图片位置尽量保持稳定。适应屏幕与 1:1 也恢复按图片比例计算窗口。允许窗口超出屏幕，按住图片移动整窗可查看其余部分；移到边缘时至少保留 64×48 逻辑像素可操作的一角。底部缩放工具按需显示；双击图片内部在适应屏幕与 1:1 之间切换，键盘 0 / 1 / + / − 和 Esc 继续可用。

**置顶和关闭按钮常驻显示**，定位在窗口当前可见部分的右上角。普通预览默认不置顶，悬浮图片默认置顶；开关只影响当前窗口，关闭再打开恢复对应默认状态。右键图片可以选择放大、缩小、适应屏幕、1:1、置顶或关闭；很小的窗口通过该菜单提供完整操作。

最高倍率为 1600%；真实窗口绘制面积限制为 1600 万像素，最长边不超过 8192 像素，按系统缩放换算，边框拖动也遵守窗口尺寸限制。达到上限时停止继续放大并显示实际倍率，1:1 同样受该限制。适应屏幕可将图片和窗口一起收回当前显示器工作区。移动、边框调整和滚轮操作复用已加载原图，不生成新的图片缓存，也不增加常驻窗口或后台服务。

## 文字便签

1. 点击衣架工具条的 **添加便签**，打开一张独立便签。在正文区域直接输入或粘贴文字。
2. 底部可以选择纸张颜色与编辑字号，顶部 **置顶** 只影响当前这张便签窗口。
3. 写完点击右上角 **×** 或按 **Esc**。保存成功后，新便签挂到衣架左端；点击衣架上的便签，可再次打开编辑。

可以同时打开多张不同便签，也可以同时打开多张不同图片，窗口分别移动和关闭。再次点击已打开的同一张便签或图片，会显示对应的已有窗口，便于继续查看；点击 **添加便签** 会创建另一张空白便签，不关闭其他便签。

- **衣架预览**：正文固定使用 **14px**，只显示卡片内放得下的前几行，超出部分隐藏，完整文字仍然保留。它与编辑窗口字号独立：编辑窗设置为 20px、32px 等，衣架仍显示 14px。
- **编辑字号**：14、16、18、20、24、28、32px，默认 14px，只影响当前便签的编辑窗口。
- **颜色**：奶油黄、浅樱粉、鼠尾草绿、雾蓝、米白五种预设；点击彩色圆形按钮选择 **自定义颜色**。正文颜色自动调整，保证深色便签也能阅读。
- **置顶与移动**：置顶只作用于此便签，独立于衣架的置顶开关。按住便签顶部标题栏拖动位置；也可以拖动窗口边缘调整大小。
- **关闭与保存**：关闭时保存完整正文、颜色、编辑字号、置顶状态和窗口位置；输入期间暂存当前窗口内容，新便签在关闭前不挂到衣架。空白的新便签关闭后不挂出，已有便签清空正文后仍然保留。
- **右键删除**：在衣架上的便签卡片右键，选择 **删除**，永久移除所选便签的正文和记录，并关闭它对应的编辑窗口；不能撤销。其他便签、图片与窗口保持不变。删除失败会显示原因，保留便签及对应窗口，可以解除文件占用等问题后重试。
- **保存失败**：显示原因，保留便签窗口与当前文字；请解决文件占用等问题后再次关闭重试，未成功保存时不会新增衣架卡片。
- **重新启动**：已保存便签继续挂在衣架上，点击后恢复文字、外观设置和窗口位置。程序不会在启动时自动打开全部便签窗口。正常退出程序时，会先保存已打开便签的当前内容；请使用托盘的退出按钮，避免直接结束进程。

便签采用纯文字保存，正文可换行，不会转成图片。每张便签最多 50000 个字符；中文、换行和空格会按输入内容保留。便签编辑区域的 Ctrl+V 用来粘贴文字，不会把文字当作截图挂上衣架。

## 其他操作

- **移动**：按住工具条的拖动把手或左侧标题移动，松开保存位置。
- **浏览**：在图片或便签区域使用滚轮或左右按钮横向翻看。新内容在左端。
- **预览**：点击图片打开原图，多张不同图片可同时预览，滚轮或按钮缩放，Esc 关闭当前窗口。
- **悬浮**：右键图片选择悬浮，多张图片可各自打开独立置顶窗口，可移动、缩放和关闭。关闭不删照片，也不随衣架收起。
- **删除图片**：右键图片选择删除，永久移除所选原图、缩略图、紧凑缓存、导出缓存和照片记录，关闭对应预览/悬浮窗。无法撤销，外部文件夹或聊天软件中的副本保留。占用中的缓存会继续重试清理。
- **删除便签**：右键衣架上的便签选择删除，永久移除该便签正文和记录，关闭对应编辑窗口，其他内容保持不变。
- **暂停**：暂停自动收集，仍可悬停衣架按 Ctrl+V 手动添加；恢复时跳过剪贴板当前图片，从下一张开始。
- **置顶**：切换衣架是否始终显示在其他窗口上方。
- **自动隐藏**：开启后才显示速度选择：快＝离开立即收起，中＝1 秒，慢＝2 秒。普通图片预览、置顶图片、悬浮图片及便签编辑窗口打开时，都不会暂停衣架的自动隐藏；鼠标离开衣架范围后仍按所选速度收起。图片和便签继续显示，保持各自的置顶、位置和尺寸；关闭这些窗口也不会展开已经收起的衣架。移到衣架对应的屏幕顶部后展开，恢复此前位置且不抢焦点。
- **隐藏**：手动隐藏到托盘，需从托盘恢复。手动隐藏不会因鼠标到顶部而恢复。
- **退出**：右键托盘图标选择退出，停止收集并释放快捷键。

透明空白区域允许点击穿透。窗口宽度约为所在屏幕的 40%，以工作区域为限并保留 24 逻辑像素余量；高度保持 260 逻辑像素；默认不置顶、默认关闭自动隐藏。收起和隐藏会卸下页面缩略图，恢复后保留浏览位置。

## 本地数据

默认数据目录：`%APPDATA%\screenshot-clothesline`。原图、缩略图、索引、导出缓存和窗口状态均在本机；便签正文与设置存放在同目录的 `notes.json`，旧版连接设置若存在也会保留。备份前退出程序，再复制完整数据目录。

剪贴板图片按像素和尺寸去重，自动收集和手动粘贴采用同一规则。程序只读取剪贴板，不改写它。保存失败不会新增照片；自动收集保存失败会重试，手动粘贴失败可再次按 Ctrl+V。除主动删除所选图片及其缓存、或所选便签的正文和记录外，不自动删除图片、便签或其他文件。不提供云同步、独立截图、搜索或开机自启。

## 桌面快捷方式角标

桌面快捷方式左下角的箭头由 Windows 显示。晾衣架程序没有修改快捷方式箭头的系统设置，也不使用更改其他程序图标的逻辑。当前异常角标的具体原因尚未确定，本版没有把它列为已经修复的问题；不通过修改系统注册表或删除图标缓存来处理。

## 开发与验收

Electron 44.7.0、原生 HTML / CSS / SVG、electron-builder 26.15.3。

```powershell
npm ci
npm start
npm test
npm run smoke
npm run smoke:notes
npm run dist
```

本版交付在 `release/v0.8.6`。测试结果以 `test-artifacts/v0.8.6/verification.json` 和成品验证记录为准；源码逻辑测试与真实 Electron smoke 使用隔离数据及模拟剪贴板，不修改日常剪贴板或浏览器配置。便签功能验收沿用 `docs/notes-v0.8.0.md`，本版宽度以本文的 40% 说明和本次验证记录为准。旧版交付和验收文档继续保留。

本版重点验收：暂停时手动添加、空剪贴板/文字提示、重复图片不新增、保存失败不假成功；仅悬停可见展开衣架时接管 Ctrl+V，离开或隐藏后释放；不同分辨率、100%／125%／150% 缩放下约占屏幕 40%，以及较窄工作区域适配、拖到另一显示器或显示配置改变后重新计算；小缩略图、原图预览/悬浮/导出和重启。宽度同时检查显示器逻辑尺寸、窗口边界与 PNG 像素；目标为 `floor(显示器逻辑宽度 × 0.4)`，以工作区域宽度减去 24 DIP 为上限且至少 1 DIP，高度保持 260 DIP。原生坐标与截图存在取整差异，应记录实际值，不将强制渲染比例检查当作已修改系统缩放。原生拖放测试检查完整文件载荷，跳过对外部程序实际投放。

便签重点验收：衣架便签右键删除正文和记录，只关闭所选便签的对应编辑窗口，删除失败保留内容可重试，重启后已删除便签不出现；同时打开多个图片预览和多个便签；新便签关闭前不挂出、关闭后成功保存；衣架固定 14px，独立编辑字号；预设及自定义颜色；置顶只影响当前窗口；拖动、调整大小、再次打开与重启恢复；保存失败保留内容；刚打开已有便签立即关闭或退出，不把尚未读取的正文覆盖为空；有待输入的最后几个字在正常退出时完整保存。便签与图片混排后继续检查横向浏览、自动隐藏、照片原图预览与导出，避免新增功能影响旧行为。

真实 Windows 无焦点悬停后按 Ctrl+V、Chrome/Edge 对具体素材站的复制行为、微信/资源管理器实际拖放、系统多显示器与显示缩放仍需在日常环境试用，不把模拟按键或回调测试当成系统原生快捷键实测。

开发者可用 `npm run memory` 测量全部应用进程的私有工作集，另记私有提交量和含共享页的工作集；不强制回收或裁剪工作集。特殊显卡需恢复硬件加速时，退出程序后运行 `& '.\截图晾衣架.exe' --hardware-acceleration`。
