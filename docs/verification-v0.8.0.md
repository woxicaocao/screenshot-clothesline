## 新功能

衣架上的便签可右键选择“删除”。删除成功后才移除卡片、保存记录与正文，并关闭对应的已有编辑窗口；其他便签与照片不变。已打开的未保存草稿不会在关闭或重启时复活。删除失败保留卡片、全文和窗口，可再次右键重试。

宽度改为当前显示器逻辑宽度的三分之一，适配分辨率、DPI 和跨屏后的重新计算，不再使用 1680 像素上限。当前 2560×1440、100% 环境中的真实衣架截图宽度为 853 像素。单元测试覆盖 1366 / 1600 / 1920 / 2560 / 3840 / 7680 宽度及多种 DPI；实际 Electron 强制 100% / 125% / 150% 比例的截图检查通过。工作区域不足时保留余量，窗口高度保持 260 DIP。

较窄窗口使用图标与提示保留全部工具，更窄时排成两行。独立 Edge 布局检查覆盖 213–853 DIP，但不把 mock 布局图当作成品截图。真实 Electron 验证横向滚轮时，在可见卡片内命中；透明空白仍按规则穿透。

多图片、多便签、衣架固定 14px、编辑字号独立、五种预设和自定义颜色、关闭保存、失败保留与重启恢复均保留。完整文字最多 50000 字符，衣架摘要最多 700 字符。“中🙂A”按原规则显示 3 字。新增保护并验证：焦点便签盖住衣架时，陈旧悬停状态也不会抢走便签的 Ctrl+V；移到露出的衣架区域可以继续挂图，衣架置顶盖在未置顶便签之上时仍允许挂图。

## 内存与系统图标

没有新增常驻服务或进程；已减少全文和图片索引复制。最终程序空衣架约 70.8 MiB，候选程序完整场景对照中连续图片和多窗口仍超过 100 MiB，详见同目录内存记录，不能承诺稳定低于 100 MiB。

检查了 Windows 快捷方式配置和默认角标，晾衣架没有修改系统箭头的代码。已尝试一次无删除的图标刷新；绿色样式的确切来源及是否恢复仍未确认，详见快捷方式检查记录。未删除系统图标缓存或修改注册表。
