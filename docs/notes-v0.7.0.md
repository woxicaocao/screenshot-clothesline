# 0.7.0 便签与多窗口验收

本文是本版新增功能的验收清单。实际测试结果、通过数量及截图以 `test-artifacts/v0.7.0/verification.json` 和成品验证记录为准；清单不代表每项已经测试通过。

## 设计约定

- 同一根衣架混排图片与便签，新内容挂在左端，继续采用滚轮和左右按钮横向浏览。
- “添加便签”创建独立空白编辑窗口，不关闭已打开的其他便签或图片窗口。不同图片与不同便签可同时打开；同一张内容再次打开复用对应窗口。
- 新便签关闭前不出现在衣架；关闭保存成功后才挂出。已有便签也在关闭时保存修改，保存失败保留窗口与文字。
- 衣架上的便签正文固定 14px，超出卡片边界隐藏，完整内容仍保存。编辑窗口的字号单独设置。
- 五种预设颜色与自定义颜色，置顶开关只作用于当前便签窗口。
- 点击衣架上的便签重新编辑，恢复已保存的正文、颜色、字号、置顶和窗口位置；启动时不自动打开全部便签窗口。
- 本版不增加便签删除；已有便签清空正文后仍保留。空白新便签关闭后不新增记录。

## 新功能检查

1. 连续点击“添加便签”打开至少两张新便签，同时打开至少两张不同图片预览。每个窗口都保持独立，关闭其中一个不影响其他窗口。
2. 输入包含中文、英文、换行、空格与类似 HTML 的普通文字。保存后重新打开，完整内容不丢失，不执行正文中的代码。
3. 新便签输入时衣架没有新增卡片；关闭后新增一张卡片。只改变颜色或字号的空白新便签关闭后不挂出。
4. 将编辑字号改为 20px 或 32px，衣架便签正文仍为 14px；长正文在衣架卡片中隐藏超出部分，重新打开能看到全文。
5. 依次选择五种预设颜色和自定义色，衣架与编辑窗纸张颜色保持一致；选择深色自定义背景时文字仍有足够对比。
6. 一张便签置顶、另一张不置顶，检查衣架和其他便签的置顶状态没有一起改变。
7. 拖动便签标题栏移动，拖动边缘调整尺寸，关闭后重新打开，再退出并重新启动。确认保存的内容、外观和位置恢复，位置不落到不可见屏幕外。
8. 模拟保存失败。窗口保留、文字可继续编辑，未保存的新便签不挂出；解除故障后重新关闭，成功保存。
9. 已有便签刚打开、正文尚未加载时立即触发窗口关闭或程序退出。等待读取后保存，不得用默认空文字覆盖已有内容。
10. 输入最后几个字后立刻正常退出。所有打开便签均完整保存，程序退出失败时提示原因并保留窗口。
11. 在便签正文中按 Ctrl+V，粘贴文字。确认不会把正文复制操作误当成图片收集或衣架粘贴。
12. 多张便签与图片混排，前后浏览并更新便签内容，检查固定字号、卡片顺序和计数。衣架隐藏后卸载显示卡片，恢复时内容和浏览位置仍正确。

## 旧功能回归

检查自动截图收集、暂停和恢复、鼠标悬停衣架时 Ctrl+V 手动挂图、图片像素去重、缩略图、原图预览和悬浮、原图拖出载荷、照片主动删除、衣架拖动和置顶、自动隐藏三档、托盘恢复，以及重启后的原照片和窗口状态。

衣架宽度继续以实际屏幕约 1680 像素为准；检查 100%、125%、150% 渲染比例和较窄工作区域适配。强制渲染比例截图不代表已经修改 Windows 的系统缩放。

## 验证方法与范围

- 单元测试采用临时数据目录，检查便签字段验证、保存事务、并发、损坏文件保留及失败重试；不删除用户的日常便签或截图。
- Electron smoke 使用隔离资料目录和模拟剪贴板，检查真实窗口、IPC、混合衣架卡片、正文保存与重启恢复。
- UI 检查使用独立测试窗口，确认实际渲染和字号。浏览器中注入的测试 API 只用于界面检查，不能替代 Electron 成品联调。
- Windows 日常环境的输入法、跨程序无焦点快捷键、多显示器、微信与资源管理器实际拖放仍需人工试用；未执行的项目应明确保留为未验证。
- 不把历史版本的内存数字或测试数量当成本版结果，多个原图或多个便签窗口会增加 Electron 渲染进程开销。
