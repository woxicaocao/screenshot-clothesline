# 截图晾衣架 0.8.2 验证说明

## 本次修改

普通图片预览和悬浮图片改为 1 DIP 外框，图片舞台四边距窗口均为 1 DIP。移除原来的固定宽标题栏、底栏和额外图片留白。初始窗口按原图比例确定大小，受工作区及 320×240 最小尺寸限制；很小或细长的图片仍可能留有空白，不拉伸、不裁切。

顶部 28 DIP 拖动与关闭浮层、底部 32 DIP 缩放浮层覆盖在图片上；鼠标进入窗口或键盘 Tab 聚焦工具时显示，鼠标离开且没有键盘工具焦点时隐藏。鼠标点击缩放不会让工具永久显示。图片区域保留滚轮缩放、拖动平移、双击适应与 1:1、键盘快捷键以及 Esc 关闭。

图片窗口仍按需读取原图，多窗口、同图复用、独立关闭、悬浮置顶、原图导出和删除相关窗口的规则继续使用原有机制。衣架保持屏幕宽度 40%，截图、便签及设置使用原来的数据目录。

## 验证范围

144 项逻辑测试全部通过。源码和最终 ZIP 解压版的图片功能各 29 组、便签功能各 17 组全部通过，页面错误为 0；27 个源文件、版本信息和随包说明与最终源码一致。

验证了四边 1 DIP 外框、完整图片舞台拟合、浮层不占固定空间、鼠标进入显示及离开隐藏、点击缩放后移出仍隐藏、Tab 聚焦显示、滚轮放大后平移，以及 320×240 紧凑窗口中的关闭和缩放控件。悬停检查采用真实鼠标事件，未采用替代模拟事件。

示例 640×420 原图的预览窗口为 642×422；悬浮窗口为 602×396。具体通过项、实际窗口尺寸和打包一致性以交付 `verification` 目录中的记录为准。交付截图来自最终 ZIP 解压后的程序，使用隔离数据和示例图片。

桌面验证使用独立数据目录，不修改日常剪贴板。原生拖放检查文件载荷，未实际发送图片到微信。100% / 125% / 150% 检查使用强制渲染比例，未改变 Windows 系统缩放。跨应用原生置顶、桌面点击穿透与系统拖动手感仍以日常使用为准。

本版未新增常驻服务或进程，也未重新进行内存对照测量。旧版程序、压缩包、缓存和历史测试记录全部保留。
