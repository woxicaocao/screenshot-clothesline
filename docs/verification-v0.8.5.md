# 截图晾衣架 0.8.5 验证说明

## 修复行为

旧版把普通图片预览和便签编辑窗口的整个打开期间记为自动隐藏暂停状态，置顶后仍会阻止晾衣架收起。本版移除这些独立窗口生命周期对晾衣架隐藏计时的影响。

开启自动隐藏后，普通预览、独立置顶的图片、悬浮图片及便签编辑窗口保持打开时，鼠标离开晾衣架范围仍按快、中、慢三档收起：立即、1 秒、2 秒。鼠标在衣架范围内不收起，移到对应屏幕顶部可恢复。衣架收起与展开不关闭图片或便签，不改变其置顶、位置、尺寸；关闭独立窗口也不会把已收起的衣架自动展开。

窗口边框调整、原图拖出、截图收集与本地数据继续使用原有逻辑，本版不新增常驻窗口、进程、后台轮询或图片缓存。旧版程序、交付和用户数据保留。

回归发现当前 Windows 150% 显示缩放下，图片窗口位置请求如果反复使用已取整的原生尺寸，会积累宽高误差。本版移动始终沿用最近请求的逻辑尺寸，比例缩放和边框调整成功后更新该尺寸；失败时与其他窗口状态一起回退。保持已有跨 DPI 绘制上限和拖动会话，避免连续移动改变图片大小。

显示器配置变化后的纯位置修复同样沿用请求尺寸。比例缩放或边框调整到绘制上限时，若原生回报多出尺寸，则依据实际余量收紧后再次提交，最终实际绘制面积和最长边仍受原有限制；失败保留此前状态。

## 验证记录

源码和最终 ZIP 解压程序使用独立演示目录，模拟自动隐藏控制器的鼠标位置与时间，核对三档延迟边界、普通与置顶预览、多图及悬浮并存、图片和便签同时打开、顶部恢复、窗口关闭和隐藏互不干扰。受控坐标与时间不标记为真实鼠标隐藏实测。

178 项逻辑测试全部通过，其中图片窗口与几何控制 34 项。源码和最终 ZIP 解压程序分别通过 33 组图片及衣架回归、18 组便签回归；全部页面错误为 0。最终 ZIP 内 29 个程序源文件逐字节与当前源码一致，版本元信息及随包使用说明一致。

额外使用真实 Windows 鼠标移动、生产 50 毫秒轮询和真实时钟，各完成 3 档验收，未调用模拟自动隐藏 tick。源码离开检测后的收起耗时为快 18 ms、中 1074 ms、慢 2028 ms；最终 ZIP 成品为快 49 ms、中 1103 ms、慢 2030 ms。顶部恢复耗时均在 50 ms 内，观察分辨率为 10 ms。每档在衣架内停留至少 300 ms 不收起，收起与唤回不改变普通置顶图片的可见、置顶、位置、尺寸及焦点；实际 OS 鼠标与请求坐标无偏移，结束后恢复原光标。真实鼠标验收只移动指针，不按鼠标键。

图片窗口移动和边框调整继续使用受保护的真实 Windows 鼠标测试，回归独立置顶、原图查看、缩放、便签、粘贴、保存、删除和重启。仅操作隔离测试数据，不改写日常剪贴板，不发送图片到外部聊天，不清理旧版文件。

本次 Windows 系统显示缩放为 150%，已实测原生图片内部拖移、右边与右下角边框调整、置顶按钮不触发拖动，以及最大缩放安全上限。还分别运行强制 100%／125%／150% 渲染比例检查；强制渲染比例不会更改系统设置。不同 DPI 多显示器的实际跨屏移动、其他系统缩放设置和微信/资源管理器真实拖放未在本次重新实测。

具体通过数量、源文件打包一致性及测试结果以交付 `verification` 目录中的记录为准。本版未重新进行内存对照测量，不能将历史测量数字当作本版承诺。
