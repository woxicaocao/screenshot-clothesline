# 截图晾衣架 0.7.0 验证记录

2026-10-13 已完成源码和最终 Windows x64 ZIP 解压程序验证。

- 逻辑测试：132 项通过，0 失败。
- 原有桌面功能：源码与成品各 29 组通过。
- 便签和多窗口：源码与成品各 14 组通过，全部窗口页面错误为 0。

## 本次新增功能

不同图片可以同时打开独立预览，便签可以同时打开多个编辑窗口，两者也能一起打开；同一张内容再次打开会复用已有窗口。关闭其中一个不影响其他窗口。

便签关闭并保存成功后挂上衣架。衣架正文固定为 14px，与编辑窗口字号独立，超出卡片空间隐藏。完整正文保留，衣架仅接收最多 700 字符的摘要。验证使用 1079 字符的便签，编辑窗口设置 20px，关闭后衣架仍为 14px，并且重新打开保留全文。

颜色提供五种预设和自定义颜色；深色背景自动使用浅色文字，中灰背景可使用黑字。置顶、拖动、窗口位置和字号分别作用于当前便签，保存后重启恢复。已有便签清空后保留记录，新空白便签不挂出。本版未增加便签删除。

验证了普通关闭、原生窗口关闭和正常退出时提交最新输入。保存失败会保留窗口及全文，退出保存失败会取消退出，随后可继续编辑并重试。IPC 仅允许所属窗口及主 frame 操作当前内容。

## 原有功能

验证了剪贴板图片收集、去重、暂停与恢复、悬停 Ctrl+V、缩略图及原图、图片预览与悬浮、原图拖出载荷、所选照片删除及缓存清理、衣架拖动、置顶、自动隐藏三档、托盘恢复、重启恢复和 100% / 125% / 150% 强制渲染比例。

当前验证环境屏幕为 1600×1024、系统比例 100%。衣架实际截图宽度为 1576 像素，因为窄屏需要保留 24 DIP 余量。宽度以 1680 实际像素为上限，工作区域不足时缩短；不会再次因系统缩放扩大到 2516 像素。

## 证据与范围

交付目录 `release/v0.7.0/verification` 保存源码和成品的回归记录、新功能记录及打包一致性记录。`mixed-rack.png`、`note-window.png`、`note-custom.png` 来自最终 ZIP 解压后的真实 Electron 窗口。

测试使用隔离数据目录、模拟剪贴板图片，不改写日常剪贴板。拖出测试核对原图文件载荷，未自动向微信发送图片或向资源管理器投放文件；跨应用实际置顶、桌面背景穿透、用户输入法、多显示器和 Windows 系统缩放切换仍需日常环境试用。强制渲染比例检查没有更改系统显示设置。

多个原图或便签窗口会按需创建并增加内存，关闭后释放窗口；本次不把历史版本的内存数字当作 0.7.0 的测量结果，也不承诺多个窗口打开时低于 100 MiB。
