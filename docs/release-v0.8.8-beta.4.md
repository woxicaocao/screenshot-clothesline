# 截图晾衣架 0.8.8-beta.4 · 整理成组，一起带走

**截图照常挂，参考图成组收，选中多张一起整理或拖出。** 本次公开发布保留 `beta.4` 测试版标记，包含最近四轮本地测试中新增的整理、组窗口与批量操作。

## 先了解「自动捕捉」

Windows、微信等截图工具把新图片放入剪贴板后，晾衣架自动保存并挂上；复制网页图片也可以自动收集。**按钮显示「暂停」表示正在捕捉，点击停止；显示「继续」表示已暂停，点击恢复。**

暂停后仍可点击「粘贴」、把鼠标移到展开的衣架按 **Ctrl+V**，或从本机拖入图片。启动或恢复时跳过剪贴板已有内容；重复图片不会反复挂上。

## 木夹整理，同类成组

- **拖木夹调整顺序**：图片、便签和组卡均可左右移动，插入线提示位置，两端自动滚动。
- **中央停留成组**：将单张卡片的木夹拖到另一张同类卡片中央，停留约 **350 毫秒**，看到「松手成组」后松开。移到两侧仍是排序。
- 图片与图片成组，便签与便签成组；单张内容可继续加入同类组。组卡只排序，不嵌套、不互相合并。
- **拖图片主体仍导出原图**，继续保留拖到文件夹、微信等程序的操作。

## 独立组窗口，更紧凑地看内容

- 点击组，在衣架下方打开独立浏览窗口；默认三列横向网格，内容多时纵向滚动，窄窗口自动减少列数。
- 图片只加载小缩略图，点击打开原图；便签显示颜色和摘要，摘要固定 **14px**，不随编辑字号变化。
- 组名、数量、**独立置顶**及「更多」集中在同一条顶部标题栏，减少留白。组名可直接编辑，也可右键重命名。
- 同时只保留一个组浏览窗口，切换时复用，关闭后销毁；不同图片和便签仍可同时打开多个。
- 组置顶仅影响当前组窗口。切换组时保留置顶状态，关闭后重新打开默认不置顶；打开或置顶组窗口不阻止衣架自动隐藏。

## 图片组框选与批量拖动

在图片组**空白处按住左键框选**，相交的图片出现选中标记与数量。靠近浏览区上下边缘可以继续滚动框选。

| 操作 | 效果 |
| :--- | :--- |
| Ctrl + 点击 | 增加或取消单张选择 |
| Shift + 点击 | 连续选择；Ctrl + Shift 追加范围 |
| Ctrl+A | 全选当前图片组 |
| Esc / 取消选择 | 清空选择；拖动中先取消本次拖动 |
| 拖所选图片的木夹 | 批量调整组内顺序，保留所选项相对顺序 |
| 拖所选图片的主体 | 一起拖出所选原图，格式与原始内容保留 |

一次最多批量拖动 **100 张**。超过会提示缩小范围，不会静默漏掉图片。排序失败保留原顺序和选择，可重试；原图准备失败、提前松手或取消，不会随后误启动拖动或误开预览。切换组、关闭窗口会清空临时选择，重启保留已保存顺序。便签组维持单项整理和编辑。

拖入聊天窗口后，请检查对象与附件，再确认发送。接收程序须支持相应图片格式和多文件拖放，实际接收效果由目标程序决定。

## 移出、解散与整组删除

- **右键成员 → 移出此组**：放回原组右侧，保留内容。
- **右键组 → 解散组**：按组内顺序在原位置展开，保留内容。
- **右键组 → 删除整个组**：先确认组名与数量，再永久删除组内保存内容及对应缓存，并关闭对应图片或便签窗口。**不可撤销**，拖入前的本机源文件不受影响。
- 只剩一项时自动还原普通卡片，空组自动取消。取消删除保留内容；删除失败会停止并显示已删除与保留数量，可对剩余内容重试。

## 自动隐藏与日常操作优化

- 开启「自动隐藏」后，悬停该按钮约 **0.5 秒**再弹出设置，移开按钮和面板后收起选项。
- 快＝离开立即收起，中＝1 秒，慢＝2 秒；移到对应屏幕顶部重新展开。
- 已打开或置顶的图片、便签、组窗口不阻止衣架收起。木夹整理、框选和拖入期间临时保持展开，结束或取消后恢复。
- 修复卡片间隙滚轮失效：整个卡片浏览带均可横向滚动，区域以外的透明空白继续穿透。
- 新便签优先放在衣架下方，保留约 16 逻辑像素间距；空间不足时换方向并缩小，多张新便签错开标题栏。已有便签继续恢复保存的位置。
- 自动捕捉、手动粘贴、本机图片导入、原图预览与导出、彩色便签和多窗口操作继续保留。

## 下载与升级

1. 先从托盘退出旧版，建议备份 `%APPDATA%\screenshot-clothesline` 完整目录。
2. 下载并完整解压 [Windows x64 免安装 ZIP](https://github.com/woxicaocao/screenshot-clothesline/releases/download/v0.8.8-beta.4/screenshot-clothesline-0.8.8-beta.4-win-x64.zip)。
3. 双击 **截图晾衣架.exe**。无需安装 Node.js，请一起保留旁边的配套文件。

继续沿用本机原图、便签和设置。新增 `layout.json` 仅保存顺序、组名和成员引用，不复制原图、不更改旧索引格式。不要单独删除或替换数据文件；备份时请先退出并复制整个数据目录。

源码采用 MIT 许可证。发布附件提供免安装程序、源码 ZIP、使用说明及 SHA256 校验文件；基础演示仍为 0.8.6 的实际录屏，本次分组和批量功能见项目图文。
