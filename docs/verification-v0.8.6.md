# 截图晾衣架0.8.6验证说明

工具条在自动隐藏和托盘隐藏之间新增普通「赞赏」按钮，沿用其他工具按钮的颜色、字体、悬停和窄屏图标样式。没有醒目强调、红点、启动提示或自动弹窗。

点击后按需创建独立窗口，显示用户提供的594×594二维码原图。图片保持完整比例与原有白边，二维码内容、头像和原图字节不修改。点击关闭、按Esc或使用原生关闭按钮均销毁窗口；重复点击显示已有窗口，不叠加多个二维码窗口。

新页面只开放关闭接口，衣架来源才能打开赞赏窗口。页面启用上下文隔离、沙箱及本地CSP，禁用Node集成、网络连接、导航和新窗口。二维码不写入照片索引，不写剪贴板、不自动发起付款；实际扫码及付款未测试。

赞赏不增加启动时常驻窗口或后台轮询；只有打开时增加独立窗口资源，关闭后销毁。窗口不暂停衣架自动隐藏，收起衣架或隐藏到托盘时赞赏窗口继续可见。未重新进行内存对照测试，不保证所有场景低于100MiB。

工具条图标布局断点调整为600 DIP，330 DIP以下两行各四个按钮。验证1024、768、690、601、600、550、546、540、521、512、409、331、330、307、240 DIP布局的按钮完整命中、边界和互不覆盖，覆盖新增按钮可能造成的窄屏拥挤。

源代码及解压成品均使用隔离数据进行赞赏窗口验收：默认不打开、普通按钮样式、原图哈希、完整显示、专用权限、快速重复打开复用、关闭重开、加载失败重试、自动隐藏和托盘恢复、退出关闭以及页面错误。实际结果以交付verification目录为准。旧版、视频工程和日常图片、便签数据保留。

178项原有逻辑测试通过。源码与最终ZIP解压程序分别通过7组赞赏验收和18组便签、多图回归，页面错误为0。15种工具条宽度均通过命中与边界验证；本次实际系统缩放为150%，没有修改系统显示设置。最终包内34个程序源文件（含原始二维码）逐字节与当前源码一致，程序元信息及随包说明一致。
