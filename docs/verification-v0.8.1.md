# 截图晾衣架 0.8.1 验证说明

## 本次修改

衣架宽度在 0.8.0 的屏幕三分之一基础上增加 20%，改为当前显示器宽度的 40%。尺寸使用 Windows 逻辑像素，自动适配分辨率、系统缩放和跨屏移动；工作区域不足时自动缩短，保留 24 DIP 余量。高度仍为 260 DIP。

1920 像素宽屏幕、100% 缩放时约为 768 像素；2560 像素宽屏幕、100% 缩放时约为 1024 像素；3840 像素宽屏幕、150% 缩放时约为 1536 实际像素。计算取整可能带来少量像素差异。

截图、便签、设置及已有位置沿用原数据目录。启动时重新计算宽度，不需要清理缓存或重置设置。

## 验证范围

144 项逻辑测试全部通过。源码和最终 ZIP 解压版的衣架验证各 29 组通过，解压版便签验证 17 组通过，未出现页面错误。100% / 125% / 150% 强制渲染比例下的宽度检查均通过。当前显示器为 2560×1440、100% 缩放，实际窗口及界面截图宽度均为 1024 像素。

27 个程序源文件、运行版本信息和随包使用说明与最终源码一致。具体通过项和实际窗口尺寸以本版 `verification` 目录中的记录为准；截图来自解压后的程序，使用隔离数据和示例图片。

测试使用独立数据目录，不修改日常剪贴板；原生拖放检查文件载荷，未向微信或其他应用实际发送测试图片。100% / 125% / 150% 检查采用强制渲染比例，没有修改 Windows 系统缩放设置。

旧版程序、交付压缩包和历史记录继续保留。
